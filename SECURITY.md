# Security Policy

## ⚠️ Intentionally Vulnerable Application

**IWA Pharmacy Direct is INTENTIONALLY VULNERABLE.**

This application is a demonstration and training tool. It contains deliberate security vulnerabilities
for educational purposes. **Do NOT deploy this application to the internet or any production environment.**

## Out of Scope

All vulnerabilities in this repository are **intentional and out of scope** for security reports.
Please do not submit vulnerability reports for this project.

## Purpose

This project exists to:
1. Teach developers about common security vulnerabilities
2. Demonstrate how security tools (SAST/DAST/SCA/IAST) detect vulnerabilities
3. Provide a realistic target for security tool evaluations

## Contact

For questions about using this app for security training, contact the repository maintainers.
